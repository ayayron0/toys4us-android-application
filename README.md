Toys 4 Us

Toys 4 Us is a toy-shopping mobile app built with Flutter and Dart for a Vanier College application development project. Customers can browse products, manage a cart, and place orders. The app also includes a Build-A-Toy feature for customizing a toy and previewing choices.

Features

Product browsing and product details

User sign-in and profile features

Shopping cart, checkout, and orders

Build-A-Toy customization with a visual preview

Administrative product management

Notifications and map-related features

Technologies

App: Flutter and Dart

Backend services: Firebase Authentication, Cloud Firestore, and Cloud Functions

Payments: Stripe integration

Other packages: Flutter Map, Awesome Notifications, and Flutter Text-to-Speech

Try the app

Download the final Android APK from the v1.0.0 release.

To explore the source code, open the toys4usproject folder. A local build requires Flutter and configuration for the services used by the app.
